# 세종 3D 지도

세종특별자치시 전역을 OpenStreetMap 데이터로 그리는 웹 3D 지도입니다.
빌드 과정이 없는 정적 페이지이며, 모든 지도 데이터는 **브라우저가 실행 중에** 공개 서버에서 받아옵니다.

## 여는 방법

- `index.html` 을 더블클릭해 브라우저(Chrome, Edge, Firefox, Safari 최신판)로 엽니다. 인터넷 연결이 필요합니다.
- 또는 이 폴더에서 간단한 로컬 서버를 띄워도 됩니다: `python3 -m http.server` 후 `http://localhost:8000/`.
  (일부 브라우저는 `file://` 에서 Referer 헤더를 보내지 않으므로, 검색이 막히면 로컬 서버로 여세요.)
- WebGL 이 켜져 있어야 합니다.

## 파일 구성

| 파일 | 역할 |

| `js/config.js` | **외부 주소·범위·바로 가기 목록** — 서버 주소가 바뀌면 여기만 수정 |
| `js/themes.js` | 다크/라이트 색상 팔레트 |
| `js/style.js` | OpenMapTiles 스키마용 지도 스타일 생성 |
| `js/lighting.js` | 시각별 태양 위치 → 건물 조명·하늘·음영 방향 |
| `js/icons.js` | 캔버스로 그리는 POI·도로 번호 아이콘 (외부 스프라이트 없음) |
| `js/core.js` | 저장소, 요청 큐(요청 간격 제한), 지리 계산, 오버레이 관리 |

| `js/detail.js` | 거리 수준 상세: 상호·시설명, 건물 상세 (셀 단위 요청·캐시, 공급자 구조) |

## 기능

- **지도 표현**: 도로 등급별 폭·외곽선(줌에 따라 변화), 교량·터널 구분, 램프, 일방통행 화살표, 도로 번호 방패,
  버스 전용도로, 공사 중 도로, 철도(침목 무늬)·지하철, 보행로·자전거길·계단·농로, 하천·호수·수계 이름,
  토지 피복(숲·초지·농경지·습지 등)과 토지 이용(주거·상업·학교·병원 등), 공원, 행정 경계선(광역·시군구·읍면동 수준),
  산 정상(해발 표시), POI 아이콘 15개 범주, 건물 번호(줌 17 이상), 지명(시·읍·면·동·마을).
- **3D 건물**: 높이별 색상 램프(범례 포함) / 용도별(주거·상업·공공·교육·의료·산업·종교·교통) / OSM 건물 색 / 단색, 평면 모드, 끄기.
  건물 위에 마우스를 올리면 강조, 클릭하면 팝업.
- **창문·외벽 표현 (줌 16+)**: 외벽에 층·창문 무늬(높이대·용도별로 모양이 다름), 지붕은 단색. 시간 슬라이더가 밤이면 창문 일부에 불이 켜집니다.
  줌 16 미만에서는 무늬 없이 단색으로 그려 멀리서 볼 때 무늬가 지저분해지지 않게 했습니다.
- **건물 상세 (OSM, 줌 16+ 자동)**: 화면 주변 구역의 건물을 OSM 에서 직접 받아 다시 그립니다 — 건물 이름(예: 101동), 용도, 지상·지하 층수,
  높이(height 가 없으면 층수×3 m), 지붕 형태(경사 지붕은 계단식으로 단순 표현), 외벽 색·재질, 주소, 건물 부분(building:part) 높이,
  출입구·횡단보도 표시, 건물 안 입점 상호 목록 팝업. 상세 데이터가 들어온 구역에서는 타일 건물을 숨겨 겹쳐 그리지 않으며,
  못 받았거나 건물이 0개인 구역은 타일 건물을 그대로 씁니다.
- **상호·시설명 (OSM, 줌 16+ 자동)**: 이름이 있는 상점·음식점·사무실·공방·관광·여가·의료 시설을 받아 범주 아이콘과 분류명(예: 카페, 의원)으로 표시.
  타일 POI 와 같은 이름이 60 m 안에 있으면 중복으로 보고 숨깁니다. 팝업에 분류·층·주소·전화·영업시간·웹사이트·브랜드를 OSM 에 있는 만큼 표시.
  타일 POI 표시도 줌 16 에서 넉넉히, 줌 17 이상에서는 이름 있는 것 전부 보이도록 넓혔습니다.
- **지형**: 지형 음영(태양 방향과 연동), 고도 색상, 3D 지형(과장 1–3배), 마우스 위치 고도 표시.
- **시간·조명**: 시각 슬라이더(세종 기준 태양 고도·방위 계산), 현재 시각, 하루 재생. 건물 조명과 하늘·안개 색이 바뀝니다.
- **테마**: 다크/라이트, 선택은 브라우저에 저장됩니다.
- **세종시 경계**: OSM 행정 경계를 받아 외곽선 + 바깥 어둡게. 실패하면 대략적인 사각 범위를 사용합니다.
- **검색**: 세종시 범위 안에서 장소 검색(Enter/버튼으로만 실행, 초당 1회 이하), 결과 영역 강조.
- **바로 가기 14곳**: 이름으로 OSM 검색 후 이동, 검색 실패 시 대략 좌표(있는 곳만) 사용.
- **시네마틱 투어 / 자동 회전**.
- **요청 예절**: 상세 데이터는 줌 15 타일 격자(약 1 km²) 단위로, 화면 중심 근처 최대 6칸(휴대폰 4칸)만 요청합니다. 상호와 건물은
  한 칸당 한 번의 요청으로 함께 받고, 모든 Overpass 요청(기존 레이어 포함)은 하나의 큐에서 한 번에 하나씩, 1초 이상 간격으로 보냅니다.
  화면에서 벗어난 칸은 요청하지 않거나 취소하고, 429/503/504 응답이면 5초부터 최대 2분까지 점점 길게 쉽니다.
  받은 칸은 IndexedDB 에 최대 120칸·7일 캐시합니다. 진행 상황은 화면 아래(휴대폰은 위) 작은 표시로만 알립니다.
- **OSM 추가 데이터 (Overpass, 켤 때만 현재 화면 범위 요청·캐시)**: 버스 정류장, 자전거 도로·대여소, 나무(3D), 생활 편의시설,
  읍·면·동 경계·이름.
- **도구**: 거리·면적 측정(3D 지형이 켜져 있으면 고도 단면), 화면 PNG 저장(출처 표기 포함), 현재 화면 링크 복사(테마·레이어 상태 포함).
- **접근성**: 모든 컨트롤에 레이블, 키보드 포커스 표시, 단축키(`?` 로 도움말), 휴대폰에서는 접을 수 있는 하단 패널.

## 알려진 한계

- **상호명 데이터의 한계**: 상호·시설명은 OpenStreetMap 자원봉사자가 입력한 것만 나옵니다. 한국에서는 네이버·카카오 지도에 비해
  빠진 가게가 많고 폐업이 늦게 반영될 수 있습니다. 이 지도가 모든 가게를 보여 준다고 생각하면 안 됩니다.
  `js/detail.js` 의 `SJ.detail.providers` 에 같은 형태의 공급자(`fetch(layerIds, box, ctl)` → `{ places: [...] }`)를 추가하면
  다른 출처를 붙일 수 있게 구조를 나눠 두었지만, 키가 필요한 상용 API 연동 코드는 넣지 않았습니다.
- 창문 무늬는 화면 픽셀 기준으로 반복되므로 실제 층 높이와 정확히 맞지 않습니다(분위기 표현용). 지붕 형태도 계단식 근사입니다.
- 건물 상세가 들어온 구역의 경계에 걸친 큰 건물은 드물게 타일 건물과 살짝 겹쳐 보일 수 있습니다.

- 실제 서버에 연결해 보지 못한 상태로 만들었습니다. 개발 환경에서는 외부 접속이 막혀 있어, 스키마 문서와
  자체 제작한 가짜 타일로만 시험했습니다. 처음 실제로 열 때 아래 항목을 확인하세요.
  - TileJSON/글꼴 주소: `js/config.js` 의 `tileJsonUrl`, `glyphsUrl`, `fontRegular`, `fontBold`.
  - 읍·면·동 admin_level 값(`emdAdminLevel`, 기본 `8`).
- 한글 라벨은 브라우저 글꼴로 그립니다(`localIdeographFontFamily`). 운영체제에 따라 글꼴 모양이 다를 수 있습니다.
- 건물 높이·층수는 OSM 에 입력된 값(또는 OpenMapTiles 기본값)에 따르며, 층수는 높이 ÷ 3.2 m 로 추정합니다.
  세종시 건물 상당수는 OSM 에 높이 정보가 없을 수 있습니다.
- 벡터 타일 최대 줌은 14 이므로 그보다 확대하면 같은 데이터를 확대해 보여 줍니다.
- 바로 가기의 대략 좌표는 정밀 좌표가 아닙니다. 검색이 성공하면 OSM 위치를 사용합니다.
- 태양 위치는 간이 공식이라 실제와 1° 안팎의 오차가 있고, 건물 그림자는 그리지 않습니다.
- Overpass 공용 서버는 혼잡할 때 응답이 늦거나 거절될 수 있습니다(화면에 안내가 나옵니다).
- 화면 저장은 현재 보이는 지도만 저장하며 패널 UI 는 포함하지 않습니다.
